# Bringing Web Pages to Life with CSS & JavaScript

## Overview
This project shows how to use **CSS animations** and **JavaScript functions** together to create interactive web pages.  

---

## Features
- **CSS Transitions & Animations**
  - Button hover effects
  - Keyframe box animation
- **JavaScript Functions**
  - Functions with parameters and return values
  - Example of local vs global scope
- **CSS + JS Integration**
  - Button click triggers box animation
  - Modal popup that opens and closes with animation

---

## How to Run
1. Open `index.html` in a browser.  
2. Hover over the button to see transition.  
3. Click **Animate Box** to see animation.  
4. Open and close the modal popup.  

---

## Files
- `index.html` → page structure  
- `styles.css` → styling, transitions, and animations  
- `script.js` → JavaScript functions and logic
